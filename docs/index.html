Overview¶

This breakout board is a high-performance hardware hub for the pyControl project. Driven by the cross-platform open-source GUI software, it is able to interface with a variety of peripheral devices to record inputs and control outputs for behavioral experiments.

Performance¶

The goal is to keep latency below the 1ms timestamp resolution of the pyControl framework. The high load setup is an extreme condition, where the M4 processor on the pyControl Breakout 1.2 began showing some limitations. The H7 Breakout 0.9 performs great in all conditions.

The benchmarking method is described in the pyControl manuscript (see "Framework Performance" in the results section and "Framework performance validation" in the materials and methods section).
