    Jack diagrams are drawn facing the socket with the latch on top, which is how the jacks are mounted on this board — so pin 1 is on the right. Position 5 is named SPECIAL in the schematic: DIO_C on eight ports, POW_C on ports 2 and 3.

    In firmware

    Ports are attributes on the board profile; pins are named by their position.

    # breakout_H7_08.py
from devices import BreakoutH7_08

board = BreakoutH7_08()

port = board.port_5
port.DIO_A   # "E8"  — UART7 TX
port.POW_B   # "C1"
port.UART    # 7
